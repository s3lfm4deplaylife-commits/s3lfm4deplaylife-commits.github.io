Privacy policy

Last updated: 28 November 2026

This policy covers sundown house, a private tool used only by the owner of the Sundown House YouTube channel.

What the tool accesses

With the owner's permission through Google sign-in, the tool uses the YouTube Data API and the YouTube Analytics API to upload videos to the owner's own channel, set thumbnails, add videos to playlists, update video details, and read the channel's own view, click-through and watch-time statistics.

How the data is used and stored

The sign-in token and the statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties or used for advertising. The tool does not access any other person's account or data.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements, and the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions; the local token is then deleted.
